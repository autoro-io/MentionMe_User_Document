### 構成要素

MentionMe は「ワークスペース」の中に「エージェント」を作って使います。

```
アカウント（契約の単位）
  └─ ワークスペース（チーム・部署の単位）
       ├─ メンバー          … 参加者と権限
       └─ エージェント       … 用途ごとに作る AI
            ├─ エージェント設定 … モデル、指示文（システムプロンプト）
            ├─ データソース     … 回答の根拠にする社内資料
            ├─ ツール          … Web 検索や HTTP リクエストなどの道具
            └─ 公開設定・サービス連携 … Web 公開、埋め込み、API、チャットツール連携
```

| 用語 | 意味 |
| --- | --- |
| アカウント | 契約の単位。会社情報・契約プラン・クレジットはアカウントごとに管理されます |
| ワークスペース | チーム・部署単位の管理区画。エージェントとメンバーはここに属します |
| エージェント | 用途ごとに作る AI。「人事問い合わせ」「情シス担当」のように分けて作ります |
| データソース | エージェントが回答の根拠にする社内資料 |
| システムプロンプト | エージェントへの指示文。役割・口調・禁止事項を書きます |
| バージョン | エージェント設定のスナップショット。切り戻しや比較に使います |
| クレジット | 利用量の単位。エージェントとの会話などで消費します |

:::tip
**エージェントは用途ごとに分けて作ってください。** 1つのエージェントに人事・経理・情シスの資料をすべて入れると、関係のない資料を根拠に回答しやすくなります。
:::

### 画面の構成

#### ワークスペース設定

ワークスペースを開くと、左メニューに次の項目が表示されます。

| メニュー | 用途 | 参照ページ |
| --- | --- | --- |
| エージェント | エージェントの一覧・作成 | [③-1 エージェントを作る](../../guides/create-agent/) |
| メンバー | メンバーの招待・権限管理 | [メンバーを管理する](../../implementation/3-members/) |
| モデルプロバイダー | 利用する AI モデルの接続設定 | [ワークスペースの詳細設定](../../advanced/workspace-settings/) |
| クレジット | 利用量の確認 | [利用量（クレジット）](../../advanced/credits/) |
| 一般設定 | ワークスペース名・OCR・保持期間 | [ワークスペースの詳細設定](../../advanced/workspace-settings/) |

#### エージェントのメニュー

エージェントを開くと、左メニューから各機能に移動できます。

:::note
表示されるメニューは役割によって異なります。たとえば「メンバー」はゲストには表示されず、「フィードバック」はオーナーと管理者にのみ表示されます。
:::

| メニュー | 用途 | 参照ページ |
| --- | --- | --- |
| ダッシュボード | 利用状況・消費クレジットの確認 | [利用状況を確認する](../../advanced/monitoring/) |
| プレイグラウンド | 設定を変えながら回答を試す | [③-4](../../guides/playground/) |
| エージェント設定 | モデル・システムプロンプトなどの基本設定 | [③-2](../../guides/agent-settings/) |
| バージョン管理 / バージョン比較 | 設定のスナップショットと比較 | [バージョン管理](../../advanced/versions/) |
| テスト / 対話テスト | 想定質問での品質確認 | [テストで品質を確認する](../../advanced/testing/) |
| スレッドメモリー / 会話履歴 | 会話内の記憶と過去の会話の参照方法 | [記憶の設定](../../advanced/memory/) |
| データソース | 社内資料の登録・検索テスト | [③-3](../../guides/knowledge/) |
| ツール | エージェントが使う道具の設定 | [ツールを使わせる](../../advanced/tools/) |
| サービス連携 | Slack などチャットツールとの連携 | [③-6](../../guides/integration/) |
| 公開設定 | Web 公開・埋め込み・API | [③-5](../../guides/publish/) |
| チャットログ / フィードバック | 会話内容と利用者評価の確認 | [利用状況を確認する](../../advanced/monitoring/) |
