---
title: 記憶の設定（スレッドメモリー・会話履歴）
description: 会話の中での記憶と、過去の会話の参照方法
---

エージェントが会話の文脈をどれだけ覚えておくかを設定します。

### スレッドメモリー

エージェントの左メニューから「スレッドメモリー」を選択します。

スレッドメモリーは、**1つの会話（スレッド）の中でエージェントが保持する作業用の記憶**です。たとえば利用者の所属や、相談中の案件の条件などを覚えさせておき、会話が長くなっても前提を見失わないようにします。

1. 「スレッドメモリーを有効にする」をオンにする
2. 記憶させたい項目をテンプレートとして Markdown で記述する（「サンプルから選ぶ」から雛形を選べます）
3. 「設定を保存」をクリック

```markdown
# 利用者の情報
- 所属部署:
- 役職:

# 相談内容
- 対象の手続き:
- 確認済みの事項:
```

エージェントは会話の中でこのテンプレートを埋めながら回答します。

### 会話履歴

エージェントの左メニューから「会話履歴」を選択すると、過去の会話をどのように回答に使うかを設定できます。

| 項目 | 説明 |
| --- | --- |
| 会話履歴の参照上限 | 回答時に含める直近の会話の件数。大きくすると多くの履歴を参照できますが、クレジットの消費も増えます。0 を指定すると制限なくすべての履歴を使います |
| 会話履歴を検索する | 参照上限を超えた古い会話の中から、関連性の高いものを検索して回答に含めます |
| 参照する検索結果の数 | 検索結果を上位何件まで含めるか |
| 検索結果の前後の会話数 | 検索結果の会話の前後何件まで含めるか |

:::tip
社内問い合わせのように1問1答が中心の用途では、参照上限を小さめにすると回答が速くなり、クレジットの消費も抑えられます。
:::
