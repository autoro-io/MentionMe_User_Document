## サービスの概要

### MentionMe とは何ですか

社内の資料に基づいて答える AI エージェントを、作る・試す・配る・改善するまで一貫して運用できるサービスです。管理者が資料と振る舞いを設定し、想定質問のテストで品質を確かめてから公開できます。公開後は利用者の評価と会話履歴から不足を見つけて直せ、設定はバージョンとして記録されるため、品質が落ちても元に戻せます。

### ChatGPT などの生成 AI をそのまま使うのと何が違いますか

個人が使う道具ではなく、組織で運用し改善し続ける仕組みである点が違います。

| 観点 | 一般の生成AIサービス | MentionMe |
| --- | --- | --- |
| 資料の扱い | 質問のたびに人が貼り付ける | 登録した資料を常に参照。更新すれば全員の回答に反映される |
| 使う人 | 設定した本人だけ | 設定を固定して配布。誰が使っても同じ品質 |
| 使う場所 | 専用の画面 | 普段の Slack から |
| 品質の管理 | その都度の試行錯誤 | 想定質問のテストとバージョン管理で、設定変更の前後を比較できる |
| 改善の手がかり | 会話が個人の中で閉じる | 利用者の評価と会話履歴が残り、資料不足かプロンプトの問題かを切り分けられる |

その場限りの調べものや文章作成であれば、一般の生成AIサービスの方が手軽です。MentionMe が向いているのは、**決まった資料に基づく回答を多くの人が繰り返し必要とする業務**です。

### どの AI モデルが使われますか

エージェントごとに選択できます。OpenAI・Google・Anthropic の各モデルに対応しているほか、お客さまの環境内で動くモデル（Ollama / vLLM）も選択できます。モデルの選択によって、データの送信先が変わります。

### 提供形態を教えてください

クラウド提供とオンプレミス提供があります。標準はクラウド提供です。閉域環境での利用が要件となる場合はオンプレミス提供をご検討ください。

## セキュリティとデータの取扱い

### データはどこに保管されますか

アプリケーションとデータベースは東京リージョンで運用しています。ただし、選択した AI モデルによっては、その提供事業者へ入力内容が送信されます（次の質問をご覧ください）。

### 入力した内容は外部の AI に送られますか

選択したモデルによります。

| 選択 | 送信先 |
| --- | --- |
| OpenAI / Anthropic / Google（Gemini API）の直接接続 | 各事業者（米国等） |
| Google Cloud Vertex AI | 東京リージョンで処理します |
| AWS Bedrock | 指定リージョン（東京・大阪を選択可） |
| Ollama / vLLM | お客さまが指定したサーバー |

### 入力した内容が AI の学習に使われることはありますか

MentionMe は AI モデルを各社の API 経由で利用しています。各社の API 利用規約上、API 経由で送信されたデータは原則としてモデルの学習に使われません。

### 他社（他のワークスペース）のデータと混ざることはありませんか

ワークスペース単位でデータを分離しています。別のワークスペースのデータを参照することはできません。

### 誰が何をしたかの記録は残りますか

残ります。エージェント・データソース・公開設定・APIキー・ワークスペースに対する操作を監査ログに記録しています。記録の確認が必要な場合は、担当営業にご相談ください。

### 個人情報を含む資料を登録しても大丈夫ですか

取り込み時に個人情報をマスクする機能があります（メールアドレス・電話番号・クレジットカード番号・マイナンバーなどのパターン検知と、AI による氏名・住所等の検知）。ただし、**マスキングの完全性は保証されません**。登録すべきでない情報は登録しない運用を併せてご検討ください。

### データの保持期間を教えてください

| データ | 既定の保持期間 | 変更 |
| --- | --- | --- |
| 会話履歴 | 無期限 | ワークスペース単位で保持日数を設定できます |
| トレース（本文） | 90日 | ワークスペース単位で変更できます |
| トレース（メタデータ） | 365日 | ワークスペース単位で変更できます |
| 監査ログ | 365日 | 変更できません |
| 取り込み時の原本ファイル | 処理完了時に削除（資料内の画像は、データソースが登録されている間保管） | — |

### SSO（SAML / OIDC）に対応していますか

標準はメールの確認コードによるログインです。SAML / OIDC による連携が要件となる場合は、個別にご相談ください。

## 導入と利用開始

### 使い始めるまでに何が必要ですか

おおむね次の順で進みます。

1. 新規アカウント登録（14日間の無料トライアルのお申込み）と利用開始（[アカウント登録・ログイン](../../implementation/1-sign-in/)）
2. ワークスペースの作成（[ワークスペースを作成する](../../implementation/2-workspace/)）
3. メンバーの招待
4. エージェントの作成と社内資料の登録
5. プレイグラウンドでの調整・テスト
6. Web 公開・チャットツール連携
7. 継続利用する場合は本契約へ切り替え（担当営業にご連絡ください）

### 事前に準備するものは何ですか

- 登録する資料（PDF・Office ファイルなど）
- 利用者のメールアドレス（招待に使用）
- チャットツール連携を行う場合は、該当ツールの管理者権限

### 何人まで使えますか

ご契約のプランによります。現在の利用数と上限は [アカウント設定のプラン](../../implementation/4-account/#プラン) で確認できます。

### スマートフォンから使えますか

管理画面はパソコンのブラウザでのご利用を前提としています。

## 社内資料の登録

### どんなファイル形式に対応していますか

PDF・Word・PowerPoint・Excel・CSV・テキスト・Markdown・HTML・JSON・画像（png / jpg / webp）に対応しています。1ファイルあたりの上限は 10MB です。詳しくは [③-3 社内資料を登録する](../../guides/knowledge/) をご覧ください。

### スキャンした PDF や画像の文字も読めますか

読めます。文字情報を持たない PDF や画像は OCR で文字起こしして取り込みます。1ファイルあたりのページ数には上限があるため、長大なファイルは分割して登録してください。

### 資料が多すぎると精度は落ちますか

1つのエージェントに用途の異なる資料を詰め込むと精度が落ちます。用途ごとにエージェントを分けてください。

## 回答の精度

### 精度を確認する方法はありますか

- **検索テスト**：質問に対してどの資料のどの部分が取得されるかを、スコアとあわせて確認できます
- **テスト**：想定質問と要件を登録し、設定変更の前後で品質を比較できます
- **バージョン比較**：同じ質問に対する複数バージョンの回答を横並びで比較できます

### 回答の正確性は保証されますか

AI による生成であるため、**誤った内容を回答する可能性があります**。重要な判断に用いる場合は、必ず出典の資料をご確認ください。

## チャットツール連携・公開

### どのチャットツールに対応していますか

Slack に対応しています。連携の設定はお客さま側で行います。詳しくは [③-6 チャットツールと連携する](../../guides/integration/) をご覧ください。

### 社外向けに公開できますか

できます。エージェントごとに公開ページを発行でき、Web サイトへの埋め込みにも対応しています。既定では URL を知っていれば誰でもアクセスできます。「認証を必須にする」をオンにすると MentionMe にログインしているユーザーに限定できますが、自社のメンバーだけに絞るものではありません。社外秘の資料を扱うエージェントは、チャットツール連携など利用者を限定できる方法でご利用ください。

### 自社システムから呼び出せますか

できます。エージェントごとに APIキーを発行でき、OpenAI 互換の API 形式にも対応しています。詳しくは [API で呼び出す](../../advanced/api/) をご覧ください。

## 料金と利用量

### 「クレジット」とは何ですか

AI 処理の利用量を表す単位です。会話の回数とは別の単位で、処理の内容に応じて消費します。詳しくは [利用量（クレジット）](../../advanced/credits/) をご覧ください。

### 残高がなくなるとどうなりますか

エージェントの実行が停止し、利用者には「ただいまご利用いただけません」と表示されます。消費が80%に達した時点でメールでお知らせしますので、早めに担当営業までご相談ください。
