---
title: 用語集
description: MentionMe で使う用語の説明
---

| 用語 | 説明 |
| --- | --- |
| アカウント | 契約の単位。会社情報・契約プラン・クレジットを管理します |
| ワークスペース | チーム・部署単位の管理区画。エージェントとメンバーが属します |
| エージェント | 用途ごとに作る AI。指示文・社内資料・ツールの組み合わせで動きます |
| システムプロンプト | エージェントへの指示文。役割・口調・禁止事項を書きます |
| ユーザープロンプトテンプレート | 利用者の入力の前後に自動で付け加える定型文 |
| Temperature | 回答のばらつきの度合い。小さいほど安定した回答になります |
| データソース | エージェントが回答の根拠にする社内資料 |
| RAG | 質問に関連する社内資料を検索し、その内容をもとに AI が回答する仕組み |
| Embedding モデル | 資料を検索用の数値（ベクトル）に変換するモデル |
| チャンク | 検索のために資料を分割した単位 |
| Top-K | 1回の回答で参照する検索結果の件数 |
| スコア閾値 | この値より関連度の低い検索結果を除外する設定 |
| 再ランキング | 検索結果を AI で並べ替えて精度を上げる機能 |
| OCR | 画像やスキャン PDF から文字を読み取る機能 |
| 出典（引用情報） | 回答の根拠にした資料名・ページ番号などの情報 |
| ツール | エージェントが使える道具（Web 検索、計算機、HTTP リクエストなど） |
| プレイグラウンド | 設定を変えながら回答を試す画面 |
| バージョン | エージェント設定のスナップショット |
| トラフィック配分 | 複数のバージョンに会話を振り分ける割合 |
| テストスイート / テストケース | 想定質問と、回答が満たすべき要件のまとまり / 1件分 |
| 対話テスト | AI がユーザー役になり、複数ターンの会話でエージェントを評価するテスト |
| スレッド | 1つの会話のまとまり |
| スレッドメモリー | 1つの会話の中でエージェントが保持する作業用の記憶 |
| 応答品質ドリフト検知 | 本番の会話を日次で採点し、品質の低下を検知して通知する機能 |
| トレース | 回答生成の過程（モデルへの入出力・ツール呼び出し・処理時間など）の記録 |
| クレジット | 利用量の単位。AI 処理に応じて消費します |
| APIキー | 自社システムからエージェントを呼び出すための鍵。エージェントごとに発行します |
| 個人アクセストークン | スクリプトなどから MentionMe を操作するための、利用者個人に紐づく鍵 |
| スラッグ | 公開ページの URL に使われる文字列 |
| 許可ドメイン | チャットの埋め込みを許可するサイトのドメイン |
