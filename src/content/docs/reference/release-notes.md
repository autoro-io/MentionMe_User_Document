MentionMe の更新内容を掲載します。

### 2026-11-01

#### 新機能・機能改善

- **チャットツール連携**：Microsoft Teams、LINE WORKS、Chatwork、Google Chat と連携できるようになりました。Slack では DM でも利用できます。Web サイトに埋め込めるチャットウィジェットを追加し、回答の出典も表示できるようになりました。
- **生成AIモデル・API**：AWS Bedrock、Google Cloud Vertex AI 経由のモデルを利用できるようになりました。画像入力、構造化出力のストリーミング、非同期実行と Webhook による結果通知に対応しました。
- **社内資料を使った回答（RAG）**：Word・PowerPoint・画像（OCR）の取り込み、Excel・Word の図形内テキストの抽出、複数ファイルの一括アップロードに対応しました。回答に出典（ページ番号・画像）を表示し、該当する資料がない場合は「該当なし」と回答します。メタデータによる検索対象の絞り込み、取り込み結果のプレビュー、取り込みデータの個人情報マスキングを追加しました。
- **エージェント作成**：Web ページ取得・HTTP リクエスト・日時の標準ツールを追加しました。エージェントのテンプレート保存とテンプレートからの作成、ユーザープロンプトテンプレート、エージェント一覧の検索を追加しました。
- **品質評価・モニタリング**：対話シミュレーションによるテスト、テストケースの自動生成・CSV 一括取り込み、評価結果のタグ・カテゴリ別集計を追加しました。応答内容の記録・閲覧（トレース）、応答品質の劣化検知と通知、利用者からのフィードバック（👍/👎）収集に対応しました。
- **セキュリティ・管理**：設定変更の監査ログ、ワークスペースメンバーのロール編集、ログイン保護の強化、個人アクセストークンを追加しました。チャット入力の個人情報検知、記録データの個人情報マスキング、データ保持期間の設定に対応しました。
- **契約・利用量**：利用量に応じたクレジット制を導入し、会話・モデルごとのクレジット消費量を確認できるようになりました。14 日間の無料トライアル、アカウント設定（会社情報・プロフィール・契約プラン）、お知らせ・アプリ内通知、お問い合わせフォームを追加しました。
