### ログイン

| 症状 | 対処 |
| --- | --- |
| 確認コードのメールが届かない | 迷惑メールフォルダを確認してください。社内のメールセキュリティ製品で隔離されていないか、社内のシステム管理者にもご確認ください。再送は「メールアドレスを変更する」で戻り、60秒経過後に「コードを送信」をクリックします |
| 確認コードを入力してもログインできない | 有効期限（1時間）が切れている可能性があります。コードを再送し、最新のメールのコードを入力してください |

### 回答の品質

| 症状 | 対処 |
| --- | --- |
| 資料を登録したのに回答に反映されない | 取り込みが完了し、データソースのスイッチが有効か確認 → [検索テスト](../../guides/knowledge/#検索テスト)で資料が出るか確認 |
| 関係のない資料を根拠に回答する | エージェントを用途ごとに分割してください。1つのエージェントに資料を詰め込みすぎている可能性があります |
| 資料に無いことを推測で答える | システムプロンプトに「資料に無いことは答えない」を明記し、Temperature を下げてください |
| 回答に資料名が示されない | 資料を検索していない可能性があります。プレイグラウンドで `vectorquery_tool` の表示を確認してください |
| 「該当する資料が見つかりませんでした」と返る | スコア閾値が高すぎる可能性があります。検索テストでスコアを確認し、閾値を調整してください |
| 設定を変えたら精度が下がった | [バージョン管理](../../advanced/versions/)で以前のバージョンを確認し、設定を戻してください |
| 回答が遅い | 有効にしているツールを見直し、不要なツールを無効にしてください。会話履歴の参照上限を小さくするのも有効です |

### 利用・公開

| 症状 | 対処 |
| --- | --- |
| 「利用上限に達しました」「ただいまご利用いただけません」と表示される | [クレジット](../../advanced/credits/)の残高を確認し、担当営業までご連絡ください |
| チャットツールでメンションに反応しない | 連携画面の受信先 URL と、チャットツール側のアプリ設定の URL が一致しているか確認してください。[既存アプリの繋ぎ替え](../../guides/integration/#既存の-slack-アプリを別のエージェントに繋ぎ替える)も参照してください |
| 埋め込んだチャットが表示されない | 「WEB公開」がオンになっているか、埋め込み先のドメインが「許可ドメイン」に登録されているか確認してください |
| モデル選択に赤いエラーが出る | [モデルプロバイダー](../../advanced/workspace-settings/#モデルプロバイダー)の接続先が起動しているか、接続設定が正しいか確認してください |

上記で解決しない場合は、[お問い合わせ窓口](../../reference/contact-us/)までご連絡ください。
