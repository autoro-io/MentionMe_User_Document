このページは、管理者が作成したエージェントに質問して業務に使う**利用者の方**向けです。

MentionMe のエージェントは、登録された自社のマニュアルや規程を読んで答えます。**登録されている資料の範囲でしか答えられません。** 重要な判断に使う前に、必ず根拠の資料をご自身で確認してください。

### 使い方は3通り

| 使い方 | 方法 |
| --- | --- |
| Web のチャットページ | 管理者から案内された URL を開いて質問します |
| 社内サイトに埋め込まれたチャット | サイトの隅にあるチャットボタンから質問します |
| チャットツール | Slack・Microsoft Teams などで、エージェントにメンションして質問します |

どの方法を使うかは、管理者からの案内をご確認ください。ログインが必要な場合は [ログイン](../../implementation/1-sign-in/#ログイン2回目以降) の手順でログインします。招待メールが届いている場合は、メールのリンクから参加してください。

### 質問のコツ

| よくない例 | よい例 | 理由 |
| --- | --- | --- |
| 「経費について」 | 「出張の宿泊費は1泊いくらまで精算できますか」 | 具体的なほど該当する資料を見つけやすくなります |
| 「あれの手続き教えて」 | 「育児休業の申請手続きを教えて」 | エージェントは会話の外の文脈を知りません |
| 長文で複数の質問 | 1つずつ質問する | 論点が混ざると回答が薄くなります |

会話は続けて質問できます。「もっと詳しく」「その根拠は？」といった追加の質問にも、直前のやりとりを踏まえて答えます。新しい話題に移るときは、新しい会話を始めることをおすすめします。

:::note
Web の画面では、**Enter キーでは送信されません**（Enter は改行です）。送信は入力欄の右にある送信ボタンを押すか、Ctrl + Enter（Mac は ⌘ + Enter）を押してください。
:::

### 回答の根拠（出典）を確認する

エージェントが社内資料を検索したときは、回答の中や下に根拠となった資料名が示されます。

```
（出典: 出張旅費規程_サンプル）
```

- **資料名が示されない回答は、社内資料に基づかない回答です。** 内容の正しさは保証されません
- 資料名が示されていても、該当箇所の解釈を誤っていることがあります。重要な判断の前には原典をご確認ください

### 回答を評価する

Web のチャットページでは、回答に 👍/👎 を付けたり、解決したかどうかを答えたりできます。評価は管理者がエージェントを改善するために使います。ぜひご協力ください。

### うまくいかないとき

| 症状 | 確認してください |
| --- | --- |
| 回答が返ってこない | 画面を再読み込みし、もう一度送信してください。それでも返らない場合は管理者へ |
| 送信できない | Enter では送信されません。入力欄の右の送信ボタンか、Ctrl + Enter（Mac は ⌘ + Enter）で送信してください |
| 「ただいまご利用いただけません」と表示される | 利用上限に達して一時的に停止しています。管理者にご連絡ください |
| 知っているはずの資料の内容を答えられない | その資料がまだ登録されていない可能性があります。資料名を添えて管理者へご連絡ください |
| 回答の内容が明らかに誤っている | どの質問でどう誤ったかを添えて管理者へご連絡ください |
